# 二十四节气 · 国风科普网站

> 以天时为序，与万物同频。

一个以中国传统二十四节气为主题的静态科普网站。用米白与青绿的国风视觉，把节气的交节时间、
三候物候、民间习俗、时令养生与相关古诗整理成可浏览、可交互的页面，并自动识别「今天属于哪个节气」。
另配一张黄道俯视图：点选任意节气，就能看到那一刻地球在太阳周围的哪个位置。

项目为纯前端实现，无后端、无构建步骤、无第三方依赖，下载后可直接双击打开，也可直接放到任意
静态托管平台。

---

## 一、项目简介

二十四节气是中国古人通过观察太阳周年运动，认知一年中时令、气候、物候变化规律所形成的知识体系，
2016 年被列入联合国教科文组织人类非物质文化遗产代表作名录。

本站把这一知识体系拆成三层来呈现：

1. **时间**：每个节气的公历区间、今年的具体交节日期、太阳黄经度数；
2. **物候**：每节气三候，共七十二候，用草木鸟兽的变化标记时间的推移；
3. **生活**：民俗、养生与诗词，让节气从历法走进日常。

## 二、功能一览

### 首页（index.html）

- **国风首屏**：手绘感矢量山水长卷 + 大字标题 + 竖排题识，进入即有画面感；
- **当令节气**：脚本根据访问当天的日期自动推算所处节气，展示节气名、拼音、交节区间、
  「第几天 / 共几天」、距下一个节气的天数，并以一条二十四节气刻度尺标出当前位置；
- **四季卡片**：春、夏、秋、冬四个区块，各含六个节气卡片，共 24 张，卡片显示序号、名称、
  拼音、日期区间、黄经与一句物候短语，当前节气带「当令」标记；
- **节气歌**：四句韵语，作为页面节奏的过渡；
- **节气小问答**：8 道单选题，即时判分、逐题解析、结束时给出成绩与建议，可重新作答。

### 节气详情页（pages/detail.html?id=xxx）

- 题头：节气名、拼音、标语、交节时间、今年交节日期、太阳黄经、所属季节位置、农谚；
- 节气释义、三候物候（初候 / 二候 / 三候，各五天）、民间习俗三条、时令养生三条、相关古诗一首；
- **前后切换**：底部「上一个 / 下一个节气」可循环跳转，下方还有二十四节气索引条，当前节气高亮；
- 无参数访问时自动回落到当天的当令节气，非法参数也会安全回退。

### 黄道俯视图（pages/orbit.html）

- 一张从黄道北极往下看的俯视图：圆心是太阳，圆环上是二十四节气各自对应的**地球位置**；
- 点任意节气（或点击「上一个 / 下一个」），地球沿轨道滑到该位置，动画约 0.5 秒；
- 地球被画成明暗两半，亮的一半永远朝向太阳；地轴竖直、北端固定朝上，
  于是冬至时北半球整个转进背光面，夏至时反过来——季节的成因一眼可见；
- 旁边的读数面板同步给出：太阳黄经、地球所在黄经、日地距离（含与平均值 1.496 亿公里的比较）、
  北半球昼夜长短与变化趋势，并附一句该节气的说明；
- 四个方位标注明写「太阳黄经」，避免把「地球在下方」误读成「太阳在下方」；
- 打开页面默认对准当令节气，全部用原生 SVG 拼绘，无图表库。

### 关于页（pages/about.html）

节气定义、能指导生活的原因、两千多年历史脉络、二十四节气与太阳黄经对照表、
四个常见疑问（用原生 `<details>` 折叠，无需脚本）以及本站说明。

### 交互与体验

- 卡片悬停：上浮、阴影加深、插图轻微放大、内描边显现、箭头滑入；
- 滚动淡入：基于 `IntersectionObserver`，元素进入视口时错峰渐显；
- 平滑滚动：页内锚点跳转带吸顶偏移补偿；
- 移动端折叠菜单、返回顶部按钮；
- 全站响应式：桌面三列、平板两列、手机单列；首屏、卡片、横条均有独立断点处理；
- 无障碍：跳过导航链接、`aria-current` / `aria-expanded` / `aria-label`、键盘可见焦点、
  图片替代文本，并尊重系统「减少动态效果」偏好。

## 四、本地运行方式

三种方式任选其一，都不需要安装依赖或执行构建。

### 方式一：直接双击（最简单）

双击 `index.html` 即可在浏览器中打开。所有资源都是相对路径，`file://` 协议下可完整运行，
包括自动识别节气、切页与答题。

### 方式二：本地静态服务器（推荐，行为与线上一致）

在项目根目录（即本 README 所在目录）执行：

```bash
# Python 3
python -m http.server 8080

# 或 Node.js（若已安装）
npx serve .
```

然后访问 <http://localhost:8080/>。注意端口只影响本机访问，与部署无关。

### 方式三：编辑器插件

在 VS Code 中安装 Live Server 插件，右键 `index.html` → 「Open with Live Server」。

## 五、部署到任意静态托管

本站没有任何服务端逻辑，也不依赖特定域名或平台，**部署时把整个目录原样上传即可**：

| 平台 | 操作方式 |
| --- | --- |
| GitHub Pages | 推送到仓库，Settings → Pages 选择分支根目录 |
| Netlify / Vercel / Cloudflare Pages | 直接拖入目录，构建命令留空，输出目录填 `/` |
| 对象存储（OSS / COS / S3） | 上传全部文件，开启静态网站托管，默认首页设为 `index.html` |
| Nginx / Apache | 把目录放到站点根目录或任意子目录 |

因为所有引用都是相对路径：

- 部署在**根目录**（`https://example.com/`）正常；
- 部署在**子目录**（`https://example.com/solar-terms/`）同样正常；
- 绑定**任意域名**、启用 HTTPS、加 CDN 都不需要改动任何代码。

## 六、技术说明

### 技术栈

- HTML5 语义化标签（`header` / `main` / `section` / `article` / `nav` / `footer`）；
- CSS3：自定义属性（CSS 变量）、Grid、Flex、`clamp()` 流式字号、`aspect-ratio`、
  `backdrop-filter`、`prefers-reduced-motion`；
- 原生 JavaScript（ES5 语法为主的 IIFE 模块写法），无框架、无打包、无 polyfill；
- 全部代码带中文注释，按「数据 / 公共能力 / 页面渲染」分层。

### 零外部依赖

- 不引用任何 CDN、在线字体、图标库、统计脚本或第三方图片；
- 字体使用系统自带的宋体类衬线字体栈（`Songti SC` / `STSong` / `SimSun` 等），不产生网络请求；
- 所有插画为自制 SVG 矢量图，可无损缩放，单张 3–15 KB。

### 节气日期如何推算

`js/common.js` 使用天文近似算法：以 1900 年小寒为基准，按回归年长度
（31556925974.7 毫秒）累加，再叠加每个节气的分钟偏移量表，得到该节气所在的公历日期。

```js
// 偏移表以「小寒」为首，而数据数组以「立春」为首，故做一次顺序换算
var minutes = TERM_MINUTES[(index + 2) % 24];
var ms = 31556925974.7 * (year - 1900) + minutes * 60000 + Date.UTC(1900, 0, 6, 2, 5);
```

识别「当前节气」时，程序取上一年、本年、下一年共 72 个节气按日期排序，
找到今天落在哪个区间，并顺带算出「本节气第几天」「距下一个节气几天」「已走过比例」，
因此跨年（如 1 月 1 日处于冬至与小寒之间）也能正确处理。

> 该算法为天文近似，个别年份可能与权威历书相差一天以内，仅用于科普展示，不作历法依据。
> 详情页中的「今年交节」即为该算法给出的当年日期。

### 黄道俯视图怎么画

节气给定的是**太阳黄经** λ（春分 0°、夏至 90°、秋分 180°、冬至 270°）。地球与太阳永远分处
两端，所以地球所在黄经直接是 `(λ + 180) % 360`，画在半径固定的圆上即可。屏幕纵轴向下，
而黄经逆时针增大，因此坐标换算时 y 取反：

```js
function api(lon, r) {
  var a = lon * Math.PI / 180;
  return { x: CX + r * Math.cos(a), y: CY - r * Math.sin(a) };
}
```

昼半球用一段半圆弧填充：以晨昏线为直径，从「地球指向太阳的方向 +90°」逆时针画到「−90°」，
经过的正是朝向太阳的那一侧。地轴方向在空间中基本固定，投影到俯视图上恒为竖直，
于是二分日晨昏线正好切过两极、昼夜平分；二至日极圈内出现极昼极夜——这些都不是特意图解，
而是同一套坐标算出来的结果。

日地距离用近日点近似：近日点约在太阳黄经 282.5°（每年 1 月初），

```js
var au = 1 - 0.0167 * Math.cos((lonSun - 282.5) * Math.PI / 180); // 天文单位
```

太阳直射点纬度按 sinδ = sin23.44° · sinλ 计算。两式算下来，小寒最近（约 1.471 亿公里）、
小暑最远（约 1.521 亿公里），与天文年历一致。

### 渲染方式

- `js/data.js` 以纯对象形式承载 24 个节气的全部文本，并建立 `id → 节气` 索引；
- 首页由 `home.js` 依据数据渲染 24 张卡片与刻度尺，详情页由 `detail.js` 依据 URL 参数渲染；
- 图片路径通过 `window.SITE_BASE`（根目录为空、`pages/` 下为 `../`）统一拼接，
  保证同一份数据在两种目录层级下都能正确取图。

## 七、内容与资料来源

- 节气源流与黄经：《淮南子·天文训》、历代《律历志》

所有文字均重新撰写与整理，用于教学与科普展示。

## 八、二次开发指引

**改配色**：编辑 `css/base.css` 顶部 `:root` 中的变量即可全站生效；
四季强调色在 `css/home.css` 的 `.season-block--spring` 等四条规则中。

**改文案/加内容**：`js/data.js` 中每个节气是一个对象，字段含义自解释
（`intro` 释义、`phenology` 三候、`customs` 民俗、`health` 养生、`poem` 诗词、`saying` 农谚）。
新增节气只需按相同结构追加条目，并把对应插画放入 `assets/images/terms/`。

**改题目**：`js/data.js` 末尾的 `quiz` 数组，`answer` 为正确选项的下标（从 0 开始）。

**换插画**：保持 4:3 比例、文件名一致即可直接替换，也可用任意位图（jpg/png/webp）替换同名文件，
同步修改 `data.js` 中的 `image` 字段后缀。
